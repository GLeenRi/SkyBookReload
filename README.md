# SkyBook EFB — Flet 1.0.4

Учебное приложение на Python + Flet. Использует объектную модель для производителей, самолётов, этапов и пунктов чек-листов. Данные исходных чек-листов перенесены из исходного проекта.

## Запуск в Windows

Рекомендуется Python 3.12–3.14. В терминале из этой папки выполните:

```powershell
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
flet run main.py
```

Можно также запустить `python main.py`.

## Что реализовано

- Flet 1.0.4 и `ft.run(main)`;
- карточки производителей и самолётов;
- чек-листы, отметки и индикатор выполнения;
- сохранение отметок в `data/checklist_state.txt`;
- отчёт с `login`, `time_in`, `time_out` в `data/session_report.txt`;
- абстрактный класс, наследование, `__eq__`, `__repr__`, `__str__`, геттеры и сеттеры;
- собственная коллекция `EntityCollection` вместо словарей для хранения и поиска данных;
- переопределённые UI-классы на базе компонентов Flet.

Чек-листы предназначены только для учебной демонстрации и не заменяют утверждённые документы производителя или эксплуатанта.
